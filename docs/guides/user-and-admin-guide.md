# VerifyID — User and Admin Guide

## 1. Overview

VerifyID is a zero-trust student document issuance and verifiable QR credential platform.

The platform supports two primary roles:

- Student
- Staff

Students can request official academic documents and track their status.

Staff can review requests, approve or reject them, issue digitally signed credentials, and monitor audit activity.

Public users can independently verify an issued credential using its Credential ID or QR code.
