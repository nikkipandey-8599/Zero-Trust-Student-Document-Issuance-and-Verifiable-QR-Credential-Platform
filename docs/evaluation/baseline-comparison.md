# VerifyID — Baseline Comparison and Evaluation

## 1. Purpose

This document compares the traditional/manual student document issuance process with the VerifyID prototype.

The purpose is to identify measurable differences in:

- Request handling
- Status visibility
- Verification
- Security controls
- Auditability
- Credential authenticity
- Revocation handling

The comparison is between a conventional manual workflow and the implemented VerifyID workflow.
